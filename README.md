# LLM Judge Self-Preference Study

This repository contains the completed Qwen/Gemma study of whether LLM judges systematically prefer LLM-generated training plans over programmatically generated plans when deterministic structural quality is controlled.

## Final study status

**Status:** finished for the current Qwen/Gemma primary study and explicit marker-level extension.

The completed study now has two final evaluation layers:

1. **Primary overall pairwise evaluation**
   - 250 structurally matched LLM-vs-programmatic pairs
   - 4 local Qwen/Gemma judge models
   - 5 repeated runs
   - 2 AB/BA positions
   - **10,000 pairwise judgment records**

2. **Secondary explicit marker-level evaluation**
   - Same 250 matched pairs
   - Same 4 judges
   - Same 5 runs and AB/BA positions
   - 9 explicit markers per record
   - **10,000 marker judgment records = 90,000 explicit marker decisions**

The study should be described as complete for the current frozen design. Future work may include a scrubbed-v2 rerun, but that is not part of the finished primary dataset.

## Core research question

Controlling for deterministic structural plan quality, do LLM judges systematically favor LLM-generated training plans over programmatically generated plans, and does this effect vary by judge family, model size, marker/rubric, or whether the plan matches the judge's own family?

## Frozen study design

Source plan families:

- `Qwen/Qwen2.5-7B-Instruct`
- `google/gemma-3-4b-it`

Programmatic controls:

- Generated by varying structural properties such as hard-day count, rest-day placement, readiness/recovery constraints, race phase, duration/load, and related plan logic.
- Programmatic plans may include LLM-filled explanation/narrative fields so empty text does not trivially reveal source.

Judge models:

- `qwen_7b_judge`
- `qwen_14b_judge`
- `gemma_4b_judge`
- `gemma_12b_judge`

No Llama source or judge is part of this completed study.

Crossed judge-family/source-family results also do not support a clean own-family preference story.

## Leakage-filtered sensitivity analysis

A post hoc leakage audit found presentation-level artifacts in some LLM-source judge-facing plans, including activity-log-like fragments such as `TrailRun |`, `km`, `avgHR`, elevation strings, ellipses, and duration-text inconsistencies. These were source-asymmetric and appeared only on LLM-side plans in the audit.

A leakage-filtered sensitivity dataset was therefore constructed by excluding any matched pair with these artifacts.

Leakage-filtered split:

- Total matched pairs: 250
- Clean pairs retained: 103
- Flagged pairs excluded: 147
- Clean primary records: 4,120
- Flagged primary records: 5,880
- Clean marker records: 4,120
- Clean marker decisions: 37,080

Clean-pair primary result:

| Split | Records | LLM wins | Programmatic wins | LLM win rate |
|---|---:|---:|---:|---:|
| Clean pairs | 4,120 | 1,419 | 2,701 | 34.44% |
| Flagged pairs | 5,880 | 2,234 | 3,646 | 37.99% |

Clean-pair explicit marker results, excluding ties:

| Marker | LLM win rate excluding ties |
|---|---:|
| `training_specificity` | 48.19% |
| `readiness_alignment` | 41.45% |
| `clarity_actionability` | 40.06% |
| `recovery_safety` | 39.82% |
| `load_progression` | 37.48% |
| `plan_coherence` | 36.57% |
| `quality_session_design` | 34.03% |
| `explanation_quality` | 32.30% |
| `endurance_development` | 29.39% |

This is an exclusion-based sensitivity analysis, not a scrubbed-v2 rerun. The clean subset is smaller and less source-family-balanced, so it should not replace the primary analysis. It does show that the main qualitative conclusion does not reverse after excluding leakage-flagged pairs.

## Main conclusion for the current report

The completed study does not provide evidence that Qwen/Gemma LLM judges systematically prefer LLM-source training plans over structurally matched programmatic plans. Across primary overall judgments and explicit marker-level ratings, programmatic plans were preferred more often. The evidence also does not support a robust self-family preference effect. However, large AB/BA position effects and post hoc presentation-leakage findings must be treated as central validity considerations.
